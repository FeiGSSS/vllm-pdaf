# Targeted collision check: prefix cohorts, KV lifetimes, and distributed nodes

2026-09-05. Bounded follow-up, approximately nine minutes. Inputs to external services were public technical terms/titles only. This report narrows claims; it does not certify novelty. Full six-source follow-up results are preserved in `targeted-api-stdout.txt`, `targeted-api-stderr.txt`, and `targeted_api_report.md`. Complete search and primary text are in `targeted-*.json` and `target_web*.json`.

## Outcome

The candidate space is more occupied than the first audit suggested. **Prefix-homogeneous batch formation, memory-over-time request ranking, nonadditive shared-prefix capacity, joint request/prefix residency, and distributed query-to-prefix-segment execution all have direct prior mechanisms.** A defensible residue must establish an interaction that these mechanisms and their combination cannot already exploit. A different name, placement, or objective term by itself is insufficient.

## Last-reference release: what is established

[vLLM’s primary prefix-cache design](https://docs.vllm.ai/en/v0.8.1/design/automatic_prefix_caching.html) permits eviction of blocks only when current-request reference count is zero, then uses LRU and prefix-position ordering. [SGLang](https://arxiv.org/html/2312.07104#S3) uses reference counts for running requests and evicts zero-reference leaves, with cache-aware request ordering. **Reference counting and a zero-reference eviction frontier are established.** A request completing can make some suffix/shared nodes eligible without freeing ancestors still held by other requests; that nonadditivity is not itself new.

Three lifetimes must remain distinct: (1) queued/in-flight execution pins, (2) active-request ownership, and (3) retained cache residency for future requests. Kernel completion may end a pin but not request ownership; the final request may end ownership but leave a useful cached block resident. An objective based on reclaimable bytes must state which lifetime changes and must not count shared bytes once per request.

Feather models active working-set changes; TOPAS explicitly charges unique shared prefixes once and couples the retained set to active request choices; PRISM models future demand for retained anchors. None of these inspected sections established the exact objective “choose asynchronous same-layer A/F cohorts to minimize the time integral of the union of pinned physical prefix nodes while maintaining FFN efficiency and SLOs.” This remains a **narrow, unverified question**, not a recommendation that novelty exists.

## Other named and adjacent checks

- **Preble**, [§3.2–3.3](https://arxiv.org/html/2407.00023#S3): combines cache reuse, anticipated load, eviction/recomputation cost, and fair prefix-hit-ratio quotas. Local scheduler tracks active users of tree nodes. This is stronger than simplistic prefix-affinity routing, but its request placement/local batching differs from a remote attention-node DAG.
- **SGLang distributed RadixAttention**, [Appendix A.4](https://arxiv.org/html/2312.07104#A1.SS4): meta-tree routes requests to workers maintaining local subtrees. This establishes distributed prefix metadata, not by itself cross-worker execution over one request’s split prefix. TokenLake is the stronger collision for the latter.
- **QLM**, [§4–7](https://arxiv.org/html/2407.00047#S4): request groups/virtual queues, waiting-time estimation, SLO-aware ordering and serving operations (pulling, eviction, load balancing, model swapping). It does not establish a shared physical-prefix last-reference objective in inspected methods.
- **Competitive Non-Clairvoyant KV-Cache Scheduling for LLM Inference**, [§2.1](https://arxiv.org/html/2601.22996#S2.SS1): geometric slicing/restarts and staggered pipelines under growing KV memory. Formal model has offline arrivals, identical prompt lengths, and **additive per-job memory**; equal prompt length is not shared physical prompt storage. This is relevant theory, not a solution to the candidate shared-set objective.
- **HotPrefix**, [primary author PDF](https://cs.nju.edu.cn/tianchen/lunwen/2026/sigmod26-liyuhang.pdf): per-prefix hotness, selective host admission, hotness-aware eviction and promotion; this addresses residency/reuse/I/O, not an exact per-layer release frontier.
- **CacheBlend**, [§4–5](https://arxiv.org/html/2405.16444#S4): selective KV recomputation restores interactions among independently cached RAG chunks, with layerwise loading/recomputation overlap. It is not a drop-in exact split-attention scheduling baseline; its quality/approximation contract differs.
- **CachedAttention**: both guessed USENIX presentation and proceedings-PDF paths returned `404 page not found`, recorded in `targeted-primary3.json` and `targeted-cachedattention.json`. Bibliographic identity was located, but full methods were not retrieved in this follow-up. It is therefore an unresolved named comparison, not evidence of absence of the proposed mechanism.
- **FastServe**, [primary arXiv abstract](https://arxiv.org/abs/2305.05920): token-boundary preemption with skip-join MLFQ and proactive CPU/GPU state swapping. This bounded follow-up checked the abstract/repository description, not its complete methods; no categorical absence claim follows.
- **ChunkAttention**, [§3](https://arxiv.org/html/2402.15220#S3): prefix-aware chunk tree plus two-phase partition for shared-prefix computation. It reinforces the local-kernel collision, alongside Hydragen/Cascade already documented.

## Boundary for any next investigation

Do not position a candidate as first prefix-aware scheduling, first KV memory-time scheduling, first prefix-state/request co-design, first node-local query aggregation, or first distributed shared-prefix attention. A viable next check would inspect TokenLake query batching and CoDec’s dependency/reduction executor, then evaluate the exact same proposed policy with and without an explicit physical-node last-reference term. Preserve the same requests, prefix-sharing graph, kernels, device topology, and batching capacity. Improvement over deliberately missing these known mechanisms would not establish the contribution.
